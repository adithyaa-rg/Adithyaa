🆘 TROUBLESHOOTING:

  "Changes not showing?"
  → Hard refresh: Ctrl+Shift+R

  "Image not loading?"
  → Make sure file is in assets/ folder
  → Check filename matches exactly

  "PDF won't open?"
  → Verify file is in documents/ folder
  → Check filename is exact

  "Something looks weird?"
  → Check browser console (F12)
  → Search README.md for the issue
