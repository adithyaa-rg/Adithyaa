Research Interests

Imitation Learning

Developing frameworks for learning from demonstrations, particularly focused on state-only imitation learning where agents must learn optimal policies from sparse expert demonstrations with mismatched dynamics. My work explores sub-trajectory identification and contrastive likelihood-ratio scoring to identify expert-like behaviors in unlabeled datasets.

Offline Reinforcement Learning Behavioral Cloning Sub-trajectory Learning
Human-Machine Interfaces (HMIs)

Creating intuitive and safe interfaces for human-AI interaction, with particular focus on autonomous vehicle handover systems. I design physical and feedback mechanisms that enable smooth control transitions during Level 3 autonomous driving, incorporating haptic feedback, audio cues, and real-time monitoring.

Haptic Feedback User Studies Autonomous Driving
Computational Geometry

Applying geometric algorithms to solve real-world problems in 3D perception and processing. My work includes point cloud denoising using Delaunay Triangulation, feature-preserving processing at scale, and developing lightweight algorithms that overcome the cubic scaling bottlenecks of deep learning approaches.

Point Cloud Processing Delaunay Triangulation 3D Vision
